Unidad de Trabajo 2 · RA 2 (Peso: 22% del Módulo — Mayor Ponderación)

Creación y Estructuración de Interfaces con Hojas de Estilo (CSS3)

⏱️ 22 Horas · 1.er Trimestre
🏛️ Principio de Separación de Responsabilidades (Demostración CSS Zen Garden): El documento HTML5 aporta exclusivamente el esqueleto semántico (<header>, <nav>, <main>, <article>, <aside>, <footer>), mientras que CSS3 controla al 100% la capa de presentación visual. Una misma estructura HTML puede transformar radicalmente su diseño cambiando únicamente su hoja de estilos externa.
1. Estilos Directos (In-line) (1,0,0,0)
<p style="color: red;">...</p>

Contras: Mezcla HTML y presentación, rompe el mantenimiento y anula casi cualquier regla externa. Evitar en producción.

2. Hoja Interna (<style>) <head>
<style> h1 { color: navy; } </style>

Uso: Útil para prototipos rápidos de una sola página o CSS crítico inicial, pero no se reutiliza en sitios multipágina.

3. Hoja Externa (<link>) ✅ Estándar
<link rel="stylesheet" href="styles.css">

Pros: Separación total, caché del navegador, modularidad y soporte para hojas alternativas / temas dinámicos.

ALGORITMO DE RESOLUCIÓN DEL NAVEGADOR

Duelo Interactivo de Especificidad CSS (A, B, C, D) y Herencia

La especificidad se calcula como una tupla de 4 columnas: A (style="" en línea) · B (IDs #id) · C (Clases .clase, atributos [type], pseudoclases :hover) · D (Etiquetas p, pseudoelementos ::before).

Tupla (A, B, C, D) = (0, 1, 1, 0)
Tupla (A, B, C, D) = (0, 0, 2, 5)
🏆 Prevalece la Regla 1 (0,1,1,0) sobre (0,0,2,5). Una columna superior (ej. ID en B) gana siempre a cualquier suma de columnas inferiores.
inherit

Fuerza a heredar el valor computado del elemento padre (útil en border o margin).

initial

Restaura la propiedad al valor inicial definido por la especificación oficial W3C.

unset

Actúa como inherit si la propiedad se hereda por defecto (ej. color), o como initial si no.

revert

Revierte la propiedad al estilo por defecto de la hoja de estilos del navegador (User Agent).

FLUJO NORMAL Y ESCALADO

Elementos de Bloque vs. En Línea y Unidades

📦 De Bloque (Block)

<div>, <p>, <section>, <h1>. Ocupan el 100% del ancho disponible y provocan salto de línea.

✏️ En Línea (Inline)

<strong>, <em>, <span>, <a>. Fluyen dentro del texto y no aceptan width/height.

📏 Unidades Absolutas vs. Relativas en CSS3:

  • px (Absoluta): Píxeles CSS fijos. Útil en bordes finos (1px), desaconsejada para tipografía fluida.
  • rem (Relativa a raíz): Relativa al font-size de <html> (16px por defecto). Estándar de oro en accesibilidad.
  • em (Relativa al padre): Escala respecto al tamaño de fuente del contenedor padre directo.
  • vw / vh / % (Viewport/Padre): 1vw = 1% del ancho visible de ventana; 1vh = 1% del alto.

UT 2.4 · DISEÑO WEB ADAPTATIVO (MOBILE FIRST)

Resolución Física vs. CSS vs. Viewport y Validación W3C

1. Física Píxeles reales de hardware del panel (ej. 1170×2532 px).
2. Lógica CSS Ancho device-width de referencia (ej. 390px en Retina 3x).
3. Viewport Área visible activada por <meta name="viewport">.

Metodología Mobile First: Escribimos primero los estilos base para móvil (1 columna, sin media query) y añadimos progresivamente puntos de ruptura ascendentes con @media (min-width: 48rem) (768px) y @media (min-width: 64rem) (1024px).

✅ Calidad Técnica y Auditoría: Combina Variables CSS (:root y var()) para mantener sincronizada la Guía de Estilo viva y valida siempre la sintaxis oficial con W3C CSS Validator.

IMAGEN DIGITAL Y RENDIMIENTO (CE 3.b · CE 3.g)

Gráficos Vectoriales (SVG) vs. Rasterizados (AVIF, WebP, PNG, JPEG)

SVG (Vectorial XML) Nitidez infinita · Manipulable CSS
Mapa de Bits (Raster) Rejilla fija de píxeles (pixela)
AVIF & WebP (Modernos): Compresión de última generación (hasta 50% más ligeros que JPEG/PNG) con soporte de transparencia alfa.
JPEG & PNG (Clásicos): JPEG para fotografía sin transparencia (compresión con pérdida); PNG para capturas o transparencia sin pérdida.

AUDIO Y VÍDEO DIGITAL (CE 3.e)

Anatomía Multimedia: Contenedor vs. Códec vs. Bitrate

📦 Contenedor (.mp4, .webm, .ogg) Archivo envoltorio

Es la "caja" que empaqueta sincronizadamente la pista de vídeo, la pista de audio y los metadatos/subtítulos.

🎞️ Códec de Vídeo Algoritmo que comprime los fotogramas: H.264 (universal), VP9 y AV1 (alta eficiencia).
🔊 Códec de Audio Algoritmo sonoro: AAC (estándar en MP4), Opus y Vorbis (en WebM/OGG).
⚡ Bitrate (Tasa de transferencia): Bits procesados por segundo (kbps / Mbps). Determina el equilibrio entre nitidez visual/sonora y consumo de datos móviles.

MOVIMIENTO Y RENDIMIENTO (CE 3.f)

Animación Web: Aceleración GPU vs. Formatos Pesados

Para microinteracciones y movimiento en interfaz, prioriza siempre propiedades animables en la capa de composición de la GPU:

🚀 Animaciones CSS3 (transform y opacity) 60 FPS · ~1 KB

Mediante transition y @keyframes. No provocan recálculo del layout (Reflow) y se ejecutan directamente en la GPU.

✨ Animación SVG (CSS / SMIL / JS) 60 FPS · ~3 KB

Ideal para logotipos animados, iconos interactivos e infografías vectoriales nítidas a cualquier resolución.

🐢 GIF Animado Clásico (Obsoleto para UI) Limitado 256 colores · Alto peso

Archivo muy pesado sin control de reproducción. Debe sustituirse por vídeo MP4/WebM corto o animaciones CSS/SVG.

En Figma diseñas una barra de navegación con Auto Layout horizontal, pero al maquetar dudas entre usar CSS Grid de 12 columnas o Flexbox. ¿Cuál es la equivalencia directa y por qué?

Solución: Flexbox (display: flex). Auto Layout implementa visualmente el modelo unidimensional de Flexbox (eje principal y eje transversal), ideal para barras de navegación y componentes internos, mientras que CSS Grid se reserva para estructuras bidimensionales.
